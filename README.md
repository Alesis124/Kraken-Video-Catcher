# Kraken Video Catcher

Chrome extension (Manifest V3) that detects and downloads videos from web pages: HLS streams (`.m3u8`), DASH manifests (`.mpd`) and direct files (`.mp4`, etc.). It detects streams while you browse, lists them in a popup, and downloads them with a single click, producing a final `.mp4` file.

The project consists of two components that work together:

| Component | Folder | Purpose |
|---|---|---|
| Chrome extension | `kraken-catcher/` | Detects streams, captures cookies and request headers, and provides the user interface (popup). |
| Native host (Python) | `kraken-native-host/` | Downloads the segments, decrypts them, merges them, and generates the MP4 with ffmpeg. |

---

## Features

- **Automatic detection** of streams during playback (HLS, DASH, direct MP4), filtering out images, CSS, fonts, scripts and other non-video traffic.
- **Badge counter** on the extension icon showing the number of streams captured in the current tab.
- **Session reuse**: captures `Cookie`, `Referer`, `Origin`, `User-Agent` and `Accept-Language` from real browser requests, so streams that require those headers can be downloaded.
- **Full HLS support**: parses master playlists (selects the highest quality variant by `BANDWIDTH`), handles `.ts`, `.m4s`, `.aac` and `.mp4` segments, and retries each segment up to three times.
- **AES-128 decryption** for encrypted HLS streams (via `pycryptodome`), supporting explicit IVs or IVs derived from the segment index, and removing PKCS7 padding per segment.
- **MP4 generation** with ffmpeg (`-c copy`, no re-encoding) with real percentage progress.
- **Native "Save as" dialog** to choose the output location, with no intermediate Chrome download prompts.
- **Cancellation** of running downloads, plus a progress bar with speed and ETA in the popup.
- **Fallback mode**: if the native host is not installed, the extension saves the segments as `.zip` parts (about 150 MB each) through `chrome.downloads` and provides ready-to-copy PowerShell and ffmpeg commands to assemble them manually.
- **Utility buttons** to copy the stream URL or an equivalent ffmpeg command.

## Requirements

- **Operating system**: Windows or Linux.
- **Browser**: Google Chrome or another Chromium-based browser that supports Native Messaging (Chromium, Brave, Edge and Vivaldi are supported by the Linux installer).
- **Python 3** available in the `PATH`. On Windows, enable "Add to PATH" during installation. On Linux, the `tkinter` and `venv` modules are also required (`python3-tk` and `python3-venv` on Debian/Ubuntu).
- **ffmpeg** available in the `PATH`. If it is not found, the host saves the video as an unmuxed `.ts` file. You can also set the path manually by editing `FFMPEG_PATH` at the top of `host.py`.
- Python packages (installed automatically by the installer): `requests` and `pycryptodome`.

## Installation

### 1. Load the extension

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select the `kraken-catcher/` folder.
4. Copy the extension **ID** displayed under "Kraken Video Catcher".

### 2. Install the native host

#### Windows

1. Copy the `kraken-native-host/` folder to a permanent location. Do not move it afterwards, because the registry entry points to that exact path.
2. Run `install.bat` and paste the extension ID when prompted.
3. The installer will:
   - install `requests` and `pycryptodome` with pip,
   - generate `com.krakencatcher.host.json` with the correct absolute path,
   - register the host under `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.krakencatcher.host`.
4. Reload the extension in `chrome://extensions`.

#### Linux

1. Install the system prerequisites (Debian/Ubuntu example):

   ```bash
   sudo apt install python3 python3-venv python3-tk ffmpeg
   ```

2. Copy the `kraken-native-host/` folder to a permanent location and run the installer:

   ```bash
   cd kraken-native-host
   chmod +x install.sh host.sh
   ./install.sh                      # prompts for the extension ID
   # or: ./install.sh <extension-id>
   ```

3. The installer will:
   - create a virtual environment in `kraken-native-host/.venv` (with access to the system `tkinter`) and install `requests` and `pycryptodome` into it,
   - write the native messaging manifest for every supported browser detected under `~/.config` (Chrome, Chrome Beta, Chromium, Brave, Edge, Vivaldi); if none is found, it registers Google Chrome by default.
4. Reload the extension in `chrome://extensions`.

To remove the Linux installation, run `./uninstall.sh`.

Note: if you move the host folder or the extension ID changes, run the installer again. Browsers installed as Snap or Flatpak packages use sandboxed configuration paths and are not supported by the installer.

## Usage

1. Open the page containing the video and start playback.
2. When the extension icon shows a number, open the popup to see the detected streams (types such as `M3U8`, `MPD`, `MP4`).
3. Edit the file name if desired.
4. Click **Download**. The "Kraken Native Host" window opens and shows progress.
5. Once all segments are downloaded, choose where to save the `.mp4` in the dialog.

Other popup controls: **URL** (copies the stream URL), **ffmpeg** (copies an equivalent ffmpeg command) and the cancel button to stop a running download.

## How It Works

```
 +---------------+   webRequest    +------------------+
 |   Web page    | --------------> |  background.js   |  detects streams, stores
 |  (playback)   |                 | (service worker) |  cookies and headers
 +---------------+                 +--------+---------+
                                            | chrome.runtime.connectNative
                                            v
                                   +------------------+     +--------+
                                   |     host.py      | --> | ffmpeg | --> video.mp4
                                   |  (native host)   |     +--------+
                                   +------------------+

   download segments -> decrypt AES-128 -> merge into merged.ts -> remux to MP4
```

### Extension-host protocol

Messages are exchanged as JSON over Native Messaging.

```json
// Extension -> host
{"type":"DOWNLOAD_HLS","jobId":"...","m3u8Url":"...","headers":{...},"filename":"..."}
{"type":"DOWNLOAD_DIRECT","jobId":"...","url":"...","headers":{...},"filename":"..."}
{"type":"CANCEL","jobId":"..."}

// Host -> extension
{"type":"PROGRESS","jobId":"...","loaded":120,"total":749,"statusText":"120/749 segments"}
{"type":"DONE","jobId":"...","outputPath":"C:\\...\\video.mp4"}
{"type":"ERROR","jobId":"...","message":"..."}
{"type":"CANCELLED","jobId":"..."}
```

### Temporary files

Temporary files are stored in `%TEMP%\KrakenCatcher\<name>_<id>\` on Windows and `/tmp/KrakenCatcher/<name>_<id>/` on Linux, and are deleted only when the job completes successfully. If a job is cancelled or fails, the files (including `merged.ts`) are kept so they can be inspected or recovered manually.

## Troubleshooting

| Problem | Solution |
|---|---|
| The host window does not appear and the extension falls back to `.zip` files | The native host is not installed or the extension ID does not match. Run `install.bat` (Windows) or `./install.sh` (Linux) again with the correct ID. |
| Linux: `tkinter` or `venv` error during installation | Install `python3-tk` and `python3-venv` (Debian/Ubuntu), `python3-tkinter` (Fedora) or `tk` (Arch), then rerun `./install.sh`. |
| Linux: the host window does not open | The browser must be started from a graphical session so that `DISPLAY` is set. Under Wayland, XWayland must be available. |
| Linux: permission denied when launching the host | Make the launcher executable: `chmod +x host.sh host.py`. |
| Missing `requests` or `pycryptodome` | Run `pip install requests pycryptodome`. |
| Warning that ffmpeg was not found | Install ffmpeg and add it to the `PATH`, or set `FFMPEG_PATH` in `host.py`. |
| The save dialog is not visible | It may be hidden behind another window. The host attempts to bring it to the front. |
| ffmpeg appears to hang | The host stops it after 90 seconds without progress and keeps the temporary `.ts` file so it can be remuxed manually. |
| The video is not detected | Make sure playback has started, then reopen the popup. The capture list is cleared whenever the tab reloads. |
